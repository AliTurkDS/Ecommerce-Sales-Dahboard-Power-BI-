# E-Commerce Sales Dashboard – Power BI Project

This Power BI project presents an interactive e-commerce sales dashboard designed to analyze sales performance across regions, customers, and product categories. The dashboard provides real-time insights into profitability, customer trends, and payment patterns.

# Key Features:

Dynamic filters for Quarter and State selection

Six insightful visuals:

Sum of Amount by State

Count of Quantity by Payment Method

Sum of Amount by Customer Name

Count of Quantity by Category

Sum of Profit by Month

Sum of Profit by Sub-Category

Clean and user-friendly layout with a professional red-themed design

Helps identify top-performing states, products, and customer segments

# Tools Used:

Power BI

Microsoft Excel / CSV (for data source)

# Objective:
To visualize sales data effectively and support better business decisions through data-driven insights.
